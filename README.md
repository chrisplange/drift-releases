# Drift

Precise, parametric 2D sketching for Windows and macOS.

**[Download Drift](https://drift-website-c9y.pages.dev/download/)** ·
[User guide](https://drift-website-c9y.pages.dev/guide/) ·
[What's new](https://drift-website-c9y.pages.dev/releases/)

This repository holds Drift's releases (the downloads, their signed checksums and the
release notes) and its public issue tracker. It has no source code.

## Downloads

Each [release](../../releases) has:

- `Drift-<version>-windows-x64-setup.exe`: the Windows installer
- `Drift-<version>-windows-x64.zip`: Windows, no install needed
- `Drift-<version>-macos-universal.dmg`: macOS, Apple silicon and Intel
- `SHA256SUMS.txt` and `SHA256SUMS.txt.minisig`: the checksums of the files, signed with
  Drift's release key

Drift checks for updates here and installs one only when you say so, and only if it is
signed with Drift's release key.

## Reporting a problem or asking for a feature

[Open an issue](../../issues/new/choose). Please leave out anything confidential: issues
here are public, so don't attach client drawings or name clients or projects.
